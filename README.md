# 食堂雷达 · 胆子肥嘟嘟大学干饭指南

一个给大学生用的校园食堂点评推荐 demo：把点评颗粒度从「店」拆到「菜」，用小红花投票 + 可解释推荐解决「今天吃什么」。

- **在线访问**：https://ashanqing.github.io/canteen-radar/
- 技术：纯静态（HTML/CSS/原生 JS），零依赖，数据存 localStorage

## 功能

| 模块 | 说明 |
|---|---|
| 此刻 | 时段语境 + 6 个筛选条件 → 3 张可解释推荐卡；「再来一批」翻牌；**搭配推荐**（7 套组合，主食+荤+素，显示总价/热量/均分） |
| 榜单 | 小红花榜 / 性价比 / 新菜 / 雷区 / 窗口榜，附算法说明（Wilson 置信下限） |
| 食堂 | 4 个食堂 → 15 个窗口 → 51 道菜，支持搜索 |
| 我的 | 点评、收藏、避雷清单、口味画像 |
| 主题 | 日间 / 夜间双主题，跟随系统偏好，可手动切换并记住选择 |
| 形象 | 胆子肥嘟嘟大学吉祥物（抱饭盆的胖袋鼠），SVG 手绘 |

## 打分锚点

- **小红花 🌸**：一道菜一朵花一分（1–5 朵），1 朵 = 别点了，5 朵 = 明天还来
- **雷率 ⚡**：踩雷比例，单独出雷区榜，好评不能抵消差评

## 数据说明

学校「胆子肥嘟嘟大学」、食堂、窗口、菜品、评价均为虚构，仅用于演示产品结构。点评只存浏览器本地。
